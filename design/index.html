Prototype states: online · key rejected · can't reach · not HTTPS · private address

How to add a server
  1. Install the media service on the new server and give it a domain with HTTPS.
  2. On that server, create a key for Studio. It's printed once: 
    cd /srv/media && docker compose exec api cli keys:create otw-studio --quiet
    Don't add --default-user: Studio sends each member's own id, which keeps members' jobs and files apart.
  3. Paste the address and key above, test, save.
  4. To retire a key later: docker compose exec api cli keys:revoke <prefix>
